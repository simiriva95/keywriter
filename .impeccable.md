# Impeccable — Keywriter

## Design Context

### Users
Giocatori casual italiani (arrivano da un reel/social). Sessioni brevi alla scrivania, desktop-first. Zero onboarding: si sceglie una linea e si digita.

### Brand Personality
Ferroviario, nostalgico, ordinato. Il gioco deve sembrare un oggetto fisico delle FS anni '70-'80: cartelli di stazione smaltati, tabelloni Solari a palette, biglietti di cartone.

### Aesthetic Direction
Segnaletica FS retrò su mappa-carta chiara:
- Mappa full-screen (CARTO Positron) come tavolo di gioco, binario colorato per linea.
- Menu livelli = tabellone PARTENZE (fondo quasi-nero, lettere ambra).
- Parola da digitare = cartello di stazione blu smaltato con testo bianco.
- Scoreboard = pannello split-flap (mono, ambra).
- Anti-reference: dark dashboard neon, glassmorphism, gradient text.

### Palette (oklch)
- Blu segnaletica: oklch(0.36 0.11 259)
- Avorio carta: oklch(0.96 0.008 85)
- Inchiostro: oklch(0.24 0.015 260)
- Tabellone (near-black): oklch(0.21 0.01 260)
- Ambra solari: oklch(0.78 0.14 75)
- Rosso FS (errori/accenti): oklch(0.52 0.19 27)
- Neutri tintati verso hue 259.

### Typography
- Archivo (variable, width axis): segnaletica, titoli, UI. Uppercase per cartelli.
- Fragment Mono: tabelloni, statistiche, contatori.
- No Inter/Space Grotesk/IBM Plex (reflex ban).

### Design Principles
1. Ogni superficie è un oggetto ferroviario riconoscibile (cartello, tabellone, biglietto) — mai un "card" generico.
2. La mappa è il palcoscenico: UI in overlay leggeri, mai coprire il treno.
3. Feedback per battitura: ogni tasto muove il treno; l'errore lampeggia rosso FS sul cartello.
4. Ambra solo sul tabellone, blu solo sulla segnaletica: i colori hanno ruoli fissi.
5. Motion: decelerazione esponenziale (treno che frena), niente bounce.
